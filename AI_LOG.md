# AI Usage Log

## AI Tool

**Tool:** ChatGPT by OpenAI

## Purpose

I used AI mainly as a sparring partner to help me understand concepts, identify problems in code I had already written, and explore alternative ways of solving problems I was working on myself.

Since there are often many different ways to solve the same problem in programming, I find it useful to learn how something could be done differently or improved.

Any suggestions provided by AI were reviewed, understood and tested before I decided whether to use them. My main use of AI was to help me understand and improve work I had already done.

## AI Usage

### Planning and Project Structure

I used AI for guidance when deciding where some functions should be placed within the project structure, based on their responsibility and where they needed to be used.

AI was also used as a sparring partner when discussing how the project could be divided into reusable components, page-specific functionality, storage and utility functions.

### JavaScript Guidance and Debugging

I used AI to discuss ways of refactoring functions that had similar responsibilities and to identify opportunities to make my code cleaner and reduce unnecessary duplication.

When I encountered errors, I used AI to help explain what the error messages meant and to suggest where I should investigate. This included guidance on what values or parts of the application could be logged to the console to better understand where execution was failing.

When I did not understand a concept or suggestion, I asked for an explanation rather than simply implementing the suggested solution.

### CSS and Responsive Design

I mainly used AI for guidance on layout decisions, particularly when deciding when Flexbox or CSS Grid would be more appropriate.

I also used it to discuss responsive layout problems and possible ways of improving layouts I had already created.

### Accessibility and Code Review

I submitted code I had already written for AI-assisted code review.

The feedback was mainly provided as a list of possible improvements rather than replacement code. I reviewed the suggestions myself and decided which changes were relevant and important for the project.

This included feedback related to code structure, accessibility and general improvements.

### Content and Documentation

I used AI to help me understand what a README should contain and how it is normally structured.

I wrote the initial README content myself in Norwegian. AI was then used to help translate the content into English and assist with Markdown formatting.

### Design and UX

I used AI as a sparring partner during the design process to discuss choices such as colours, fonts and ways of keeping the interface visually clean.

I find it difficult to visualise different design alternatives in my head, so being able to discuss different possibilities was useful.

I also shared screenshots of designs I had already created when I was not satisfied with the result and received suggestions for possible improvements. I then decided myself which changes, if any, I wanted to make.

## What AI Was Not Used For

AI was not used to generate the core application logic prohibited by the assignment guidelines.

I implemented the core functionality myself, including API fetching, cart state, login and registration functionality, and the dynamic rendering of the home and product pages.

AI could be used to explain concepts, review code I had already written, or help me debug problems in these areas, but it was not used to generate the core implementation for me.

## How AI Suggestions Were Used

I reviewed AI suggestions carefully before deciding whether to use them.

If I did not understand a suggestion or why something worked, I asked for further explanation before making changes to my project.

Only a small amount of the AI assistance involved code snippets. Most of the assistance consisted of explanations, guidance, debugging suggestions and feedback on code I had already written.

I did not copy code into the project without understanding what it did. Any relevant suggestions were evaluated, adapted where necessary and tested in the application before being kept.
